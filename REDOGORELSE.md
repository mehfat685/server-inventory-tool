Redogörelse för server inventory tool
1. I filen kontroller.py har jag en funktion som heter kontroller_server() och där använder jag vilkor (if - else). När programmet kör ping och kontrollerar resultat.returncode. Om den retunerar 0 betyder att ping lyckades, alltså servern svarade på ping request och statusen blir up. för att if delen av kod körs. Om returnerade värdet är inte 0 körs den else delen och statusenpå servern blir down för att den svarade inte på ping request.

I kontroller.py använder jag en for loop i funktionen kontrollera_alla(). Loopen går igenom listan med servrar som vi har skickat och kollar en server i taget och anropas funktionen kontrollera_server() för varje server i listan som finns. Den funktionen hjälper mig att kontrollera alla servrar utan att jag skriva samma kod flera gånger.

I meny.py skrev jag en funktion som heter giltig_miljo(miljo). Den tar emot en miljo och kontrollerar om värdet är giltigt bland annat dev, prod och test är giltiga värde och om det är en av dem. den returnerar True annars False. Den hjälper mig att återanävnda min kod och även får en ren struktur på min kod och koden blir mer läsbart. jag använde den funktionen i lägga till en server funktionen.
